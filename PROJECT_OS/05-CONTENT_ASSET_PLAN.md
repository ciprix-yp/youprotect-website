# Content & Asset Plan

## Ce producem

- Copy (hero, value props, CTA, pagini legale, produse).
- Imagini (hero premium, produse, trust signals).
- Micro-copy pentru formulare și mesaje de confirmare.

## Pipeline simplu

1. Brief per pagină.
2. Draft copy v1.
3. Revizie tone + claritate conversie.
4. Aprobare.
5. Implementare în pagină.

## Reguli copy

- Ton: premium, consultativ, clar.
- Evităm limbaj de e-commerce clasic.
- CTA-uri consistente:
  - primary: `Vreau mostre returnabile`
  - secondary: `Book a call`
